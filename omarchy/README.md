# Dotfiles — Omarchy

The setup for the Omarchy (Arch + Hyprland) machine: a "frosted glass" desktop
in Shinkai (Tokyo Night × Material Ocean, with Tokyo Night still set up) with
rounded windows, three monitors with one main screen, and the developer tools
on top. The Zorin OS setup lives in [`../zorin`](../zorin).

## Restore

```sh
git clone https://github.com/rahuljsaliaan/Dotfiles.git
cd Dotfiles/omarchy
./install.sh --titlebars    # configs, settings, and the patched titlebar plugin
omarchy restart shell       # or log out and back in
```

`install.sh` **copies** rather than symlinks, because Omarchy's own tools write
into these folders (plugin clones, `omarchy refresh`, theme switches, the shell
saving `shell.json`). Anything it replaces is kept as `<file>.bak.<timestamp>`.
Changes made on the machine have to be copied back here by hand.

Two things it cannot do, because the apps own those settings:

- **Chromium and its web apps** (Teams, Outlook, WhatsApp, …): right-click the
  tab bar and tick *Use system title bar and borders*, so Hyprland draws the
  title bar instead of Chromium's own buttons.
- **Brave / Obsidian**: Brave's *Use system title bar and borders*, and
  Obsidian's *Settings → Appearance → Window frame style → Native frame*.

## Main screen

Three monitors: the laptop (`eDP-1`), the middle BenQ on HDMI (`HDMI-A-1`) and
the right BenQ on DisplayPort (`DP-2`). The middle one is the **main screen**,
falling back to the laptop when undocked. Only the main screen gets the top
bar, the dock, the lock-screen password box and the screensaver. The names
live in `mainScreenNames` / `lockInputScreens` in the plugins and in the jq
filter in `bin/omarchy-launch-screensaver-main`, and the positions in
`hypr/monitors.lua` match each monitor by model and serial. Change them all
together for different monitors.

Super + O now sets floating explicitly, and a popped window is tiled again only if popping floated it. Super + T is Omarchy's plain float/tile toggle again: a block on floating-layout workspaces was tried as a crash precaution and removed, because it took away tiling a window there, each falling back to Omarchy's own action for windows without a Hyprpin rule. Resize keys carry plain labels so the key list and the search guide find them by what they do: Super + = / - Increase / Decrease window width, Super + Shift + = / - the height, each with Alt (a little) and Ctrl (a lot) (Omarchy's stock labels were "Shrink window left" and "Expand window down"). Super + T floats a window at the size Omarchy gives every window on a floating workspace (min(1100, 64%) x min(760, 68%) of the screen inside the bar), centred, everywhere including the Super + S scratchpad, so floating windows look the same; a scratchpad float is sized again when the scratchpad opens on another screen. Super + T twice puts a window back where it was: Hyprland tiles a window again as a brand-new one (scrolling puts it after the middle column, dwindle splits whatever has focus), so its place among the workspace's tiled windows is noted as it floats and restored as it tiles: its scrolling column (and width), or the dwindle neighbour and side it was split from |

## The patched titlebar plugin

Omarchy's titlebar plugin can reveal a button's icon on hover, but not change
its background. `titlebars/button-rest-opacity.patch` adds one option,
`plugin:hyprbars:button_rest_opacity`, so the buttons draw faint at rest and in
full colour on hover. `hypr/looknfeel.lua` loads
`~/.local/lib/omarchy-hyprland-titlebars/titlebars.so` instead of Omarchy's copy
when it was built for the installed Hyprland: `build.sh` writes the
`pacman -Q hyprland` it built against into `built-for` next to it.

A plugin built against older headers fails to load, so after a Hyprland update
Omarchy's copy is used (buttons full colour at rest) until the plugin is
rebuilt. `bin/omarchy-custom-check` rebuilds it from the post-update and
post-boot hooks; by hand, run `titlebars/build.sh` and log out and back in. To
go back to Omarchy's plugin for good, delete that `.so` and run `hyprctl reload`.

## Tracktion Waveform

Waveform Free (Tracktion's DAW) runs from its official Linux `.deb`, repackaged
for pacman by `packages/waveform14/PKGBUILD` so it installs, updates and
uninstalls like any other package. The `.deb` itself is not tracked: it sits
behind a free Tracktion account, so `install.sh` cannot fetch it.

1. Get the `.deb` with the Tracktion Download Manager (from tracktion.com, signed
   in; it saves to `~/Downloads`).
2. Copy it next to the PKGBUILD, set `pkgver` and `sha256sums` to match, and run
   `makepkg -si` there. Every library it needs is already part of Omarchy.

Updating is the same steps with the newer `.deb`; `sudo pacman -R waveform14`
removes it. Opened from the launcher, it takes the current theme's colours
(see `bin/waveform-theme-sync` above).
