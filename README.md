# Dotfiles

Personal configuration for two machines, which never share a setup, so each has
its own folder and its own installer.

| Folder | Machine | What it is |
|---|---|---|
| [`zorin/`](zorin) | Zorin OS | WezTerm, zsh, tmux, Neovim (LazyVim), Starship, mise, Claude Code, and a keyboard cheatsheet. Symlinked into place by `zorin/install.sh`. |
| [`omarchy/`](omarchy) | Omarchy (Arch + Hyprland) | A Tokyo Night frosted-glass desktop: Hyprland look, a main-screen-only bar, dock, lock and screensaver, macOS-style title-bar buttons, plus Starship, Neovim and Claude Code. Copied into place by `omarchy/install.sh`. |

Each folder's README explains how to restore it and what every file does.
